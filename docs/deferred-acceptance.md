# 延后验收清单

仓库建设（P1+P1.5+P2+P3a+P3b）交付时，以下验收项因外部依赖（真实客户端、平台审核、测试账号、生产 URL、灰度时间窗）**延后执行**。本文是它们的唯一索引：每项附 RFC 章节引用与执行人占位（维护者 = 仓库维护者；业务负责人 = 按阶段介入的业务方，RFC §9 最少人力配置：1 名维护者全程 + 1 名业务负责人按阶段介入）。数据源：RFC §6 P0 附加项、§7.2.2、§7.2.3、§3.11.2。

- [ ] **一、P0 三项附加验证**（RFC §6；不阻塞 RFC 批准，但阻塞 P1 进入）
- [ ] **二、E01–E11 首期支持矩阵（Codex + WorkBuddy）**（RFC §7.2.2）
- [ ] **三、X01–X06 跨宿主可读性矩阵（占位）**（RFC §7.2.3）
- [ ] **四、P4.5 灰度观察 ≥ 3 个工作日**（RFC §3.11.2 / §6）
- [ ] **五、P5 首发**（RFC §6 / §3.11）
